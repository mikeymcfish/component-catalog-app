# Security Policy

## Supported versions

Security fixes are made on the latest version of the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub's private vulnerability reporting](https://github.com/mikeymcfish/component-catalog-app/security/advisories/new) to share:

- A clear description of the issue and its impact.
- Reproduction steps or a minimal proof of concept.
- The affected version, commit, and environment.
- Any suggested mitigation, if known.

Remove API keys, tokens, passwords, personal inventory records, uploaded files,
and other private data before submitting a report.

The maintainer will acknowledge the report when possible, investigate it, and
coordinate disclosure after a fix or mitigation is available.
